# PEtest｜复旦大学体育考试题库检索

这是一个方便复旦同学在体育理论开卷考试时查题的网页。输入题干或关键词，也可以拍照、上传图片或粘贴截图，查找相关题目、已有选项和旧题库答案。

题库来自 **[KevinWang15/fdty](https://github.com/KevinWang15/fdty)**。在原项目整理的资料基础上，我做了这个查询页面，希望让查题更方便一些。手机、电脑都能在线使用，也可以提前下载离线版。

感谢原作者和参与整理、补充资料的同学，让这些积累能够继续帮助更多人。

## 💡 为什么做这个网页

今年（2026 年）复旦大学体育理论考试改到了学习通，原来适用于旧考试网站的自动答题脚本已经无法直接使用。考虑到学习通对自动化脚本的监管相对严格，我选择把已有题库整理成一个独立的检索网页，方便大家在开卷考试时手动查找和核对题目。

虽然考试平台变了，前人整理的题库仍然有参考价值。希望通过这个网页，让这些资料继续发挥作用，也省去一些翻找的时间。

## 📖 使用方式

| 使用方式 | 打开方式 | 网络要求 |
| --- | --- | --- |
| **在线使用** | 通过浏览器打开在线入口，适用于手机和电脑 | 打开或刷新网页时需要网络 |
| **离线使用** | 下载 `index.html` 后用浏览器打开，推荐在电脑上使用 | 文字与提纲检索无需网络；图片识别需联网加载资源 |

### 🌐 在线使用

1. 打开 **[查询网页](https://fdhzy.github.io/PEtest/)**。
2. 在搜索框输入题干或关键词，查看匹配结果。
3. 点击题干或「查看详情」，查看完整题目、已有选项和来源。

默认开启「相关匹配」，完整匹配排在前面，随后补充最多 60 条相关结果；相似结果不一定是同一道题，可以结合原文核对。关闭「相关匹配」后，只显示同时包含全部关键词的内容。

多个关键词可以用空格分隔。结果较多时，可以增加关键词缩小范围；没有匹配结果时，可以缩短题干或更换关键词。

可以把网址加入浏览器收藏夹，方便下次使用。如果手机应用内打不开，可以复制网址到系统浏览器。

### 📷 拍照与图片识别

1. 展开搜索框下方的「拍照 / 图片识别查题」。
2. 手机可点「拍照识别」，也可以选择已有图片；电脑支持上传或直接粘贴截图。
3. 识别完成后会自动用题干搜索，同时保留完整识别文字，方便修改后再次查询。

尽量截取一道题，保持文字清晰、方向端正。网页会去掉开头题号，并在识别到常见 A/B/C/D 选项标记时提取前面的题干；识别错字可以直接修改。

图片在当前浏览器内处理，不上传到服务器。识别使用 [Tesseract.js](https://github.com/naptha/tesseract.js)，需联网加载识别引擎和中文语言资源，首次使用可能较慢。资源加载失败时可以重试，文字检索仍可使用。手机是否直接打开相机取决于浏览器，也可以先拍照再选择图片。

### 💻 离线使用

1. 打开仓库中的 **[index.html](./index.html)**，点击文件右上方的 **Download raw file（下载原始文件）**。
2. 将文件保存为 `index.html`（文件后缀为 `.html`）。
3. 在电脑上双击文件，或右键选择「打开方式」，使用 Edge、Chrome 等浏览器打开。

也可以 **[下载完整 ZIP](https://github.com/FDhzy/PEtest/archive/refs/heads/main.zip)**，解压后打开其中的 `index.html`。

题库和新增提纲已经包含在这个 HTML 文件里，下载后用浏览器打开就能使用。文字与提纲检索可完全离线使用，图片识别仍需要联网加载资源；离线版不会自动更新，有新版时可以重新下载。

### 🌐 内部优先，联网补充

网页先检索内部题库和提纲。在「全部内容」下，如果没有找到明确匹配，会显示百度、必应搜索入口，点击即可带上当前题干继续查询。启用题型或收藏筛选时，可先切回全部内容，避免因筛选条件遗漏内部资料。

这是免费的「本地检索 + 外部搜索跳转」版本，不会自动读取网页或生成联网答案；只有点击搜索入口时，才会把搜索框中的文字发送给所选搜索引擎。

## 🔍 主要功能

- **关键词与相关检索**：检索题干、已有选项和提纲原文，支持相关程度排序，也可切换为严格关键词匹配。
- **图片识别**：支持拍照、上传图片和粘贴截图，识别后自动搜索，文字可编辑。
- **提纲资料**：新增木兰拳和八段锦的 115 条资料，可在「提纲资料」中单独查看、收藏和复制出处。
- **完整题目查看**：点击题干或「查看详情」，查看题目、已有选项及出处。
- **题目筛选**：支持按题型筛选，或仅查看有原始选项的题目。
- **答案与收藏**：支持显示或隐藏答案、收藏题目及加载更多结果。

收藏保存在当前浏览器中，不跨设备或浏览器同步；在线版与离线版的收藏也不会自动同步。

## 📝 题库说明

目前收录 **6501 道复旦大学体育考试旧题库题目**，包括 5730 道判断题和 771 道单选题。其中，198 道单选题已恢复原始选项，另外 573 道暂时没有找到完整选项，会在页面中标注。

另收录《木兰拳理论提纲(1).docx》的 **115 条原文资料**，合计 6616 条题目与资料。原文中的重复编号、用字及表述均保留，未作事实校订；每条结果显示文件名和原条目编号。[查看提纲原文](./data/mulan-outline.md) · [结构化数据](./data/mulan-outline.json)。

补充资料使用本地全文与相关度检索，展示可核对的原文，不接入大模型生成答案，也不把资料条目当作判断题或单选题。

这份题库还没有和今年学习通的题目逐一核对，答案也沿用了旧题库内容。实际题目和选项顺序可能有变化，所以查询结果中的答案字母不一定对应当前题目的选项，需要结合具体内容判断。

数据快照：2026-11-19。网页提供手动查询功能，不包含学习通自动答题脚本。
