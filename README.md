# PEtest｜体育开卷考试快捷查询

面向体育理论开卷考试的快捷查询网页：输入题干或关键词，快速查找题目、已有选项及旧题库答案，便于在答题时核对。支持在线访问和下载后离线查询，无需安装。

包含 6501 道公开旧题库题目：5730 道判断题、771 道单选题。其中 198 道单选题已恢复原始选项，其余 573 道明确标记缺失。

> **题库来源与致谢：**本项目使用 [KevinWang15/fdty](https://github.com/KevinWang15/fdty) 公开整理的体育理论题库。感谢 [KevinWang15](https://github.com/KevinWang15) 及所有贡献者的整理、维护与无私分享；本项目在这些成果基础上制作开卷考试快捷查询页面。

## 两种使用方式

| 使用方式 | 怎么打开 | 是否需要网络 |
| --- | --- | --- |
| **在线使用（推荐）** | 点击上方「直接在线使用」，输入关键词即可检索 | 打开或刷新网页时需要网络 |
| **离线使用** | 下载 `index.html`，用浏览器打开 | 下载完成后无需网络 |

### 方式一：在线使用

1. 打开 **[https://fdhzy.github.io/PEtest/](https://fdhzy.github.io/PEtest/)**。
2. 在搜索框输入关键词或题干，即可查看匹配题目。
3. 点击题干或「查看详情」，查看完整题目、已有选项和来源。

**快捷访问：**可以把上述网址加入浏览器收藏夹，之后直接从收藏夹打开。手机如果在应用内打不开，请复制网址到系统浏览器访问。

### 方式二：离线使用

1. 打开仓库中的 **[index.html 文件](./index.html)**，点击文件右上方的 **Download raw file（下载原始文件）** 按钮。
2. 将文件保存为 `index.html`，不要保存成 `.txt`。
3. 在电脑上双击文件，或右键选择「打开方式 → Edge / Chrome / 其他浏览器」，即可开始使用。

也可以 **[下载完整 ZIP](https://github.com/FDhzy/PEtest/archive/refs/heads/main.zip)**，解压后打开其中的 `index.html`。

**题库已包含在这一个 HTML 文件里，无需安装软件、启动服务器或另外下载数据。**离线使用建议在电脑上进行；手机优先使用在线入口。

离线版不会自动更新，想获取新版时重新下载即可。在线版与离线版使用相同题库，功能一致。

## 快捷查询功能

- 输入关键词或完整题干；多个关键词用空格分隔，同时匹配。
- 点击题干或「查看详情」查看完整题目、已有选项和来源。
- 支持题型筛选、仅看有原始选项、显示/隐藏答案、收藏和加载更多。
- 收藏保存在当前浏览器中，不跨设备同步；在线版与离线版的收藏也不会自动同步。
