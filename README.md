# PEtest｜体育题库关键词检索

用于复习的纯静态网页，包含 6501 道公开旧题库题目：5730 道判断题、771 道单选题。其中 198 道单选题已恢复原始选项，其余 573 道明确标记缺失。

## 使用

下载 `index.html`，用浏览器打开即可离线使用，无需安装或启动服务器。

- 输入关键词或完整题干；多个关键词用空格分隔，同时匹配。
- 点击题干或「查看详情」查看完整题目、已有选项和来源。
- 支持题型筛选、仅看有原始选项、显示/隐藏答案、收藏和加载更多。
- 收藏保存在当前浏览器中，不跨设备同步。

## GitHub Pages

本仓库已准备好静态入口 `index.html` 和 `.nojekyll`。上传代码并不等于已开通网页托管。

在仓库 **Settings → Pages** 中启用分支部署，选择 **main / (root)** 并保存。实际访问地址以 GitHub Pages 设置页面显示为准。私有仓库是否支持 Pages 取决于账户计划与组织策略；如设置页要求升级，请先确认自己的发布方式。

## 数据来源与边界

题库来自 [KevinWang15/fdty](https://github.com/KevinWang15/fdty)，选项依据其原始文本、旧测试页面与社区留言恢复，具体来源可在题目详情查看。

数据快照：2026-11-19。未核对今年学习通版本，答案保留旧题库内容，未逐题校订。选项顺序可能不同，不能直接套用旧答案字母；缺失选项未编造。

本项目只提供本地检索与复习功能。
