# PEtest｜体育开卷考试快捷查询

开卷考试时，知道题目大概在哪儿，却半天翻不到，多少有点着急。

做这个小网页，就是想让查题方便一点：输入几个关键词，就能找到相关题目，点开查看完整题干、已有选项和旧题库答案。手机、电脑都能用，也准备了可以提前下载的离线版，希望能帮大家少花一点翻找的时间。

这个网页用到的题库，来自 **[KevinWang15/fdty](https://github.com/KevinWang15/fdty)**。感谢原作者和一路补充资料、参与纠错的同学。能做出这个查询页面，首先要感谢他们把题库整理好，并愿意公开分享。

## 在线、离线，选一个顺手的

| 你想怎么用 | 打开方式 | 网络要求 |
| --- | --- | --- |
| **直接在线查** | 点上面的在线入口，手机、电脑都可以 | 打开或刷新网页时需要网络 |
| **提前存一份** | 下载 `index.html`，用浏览器打开，推荐电脑使用 | 下载完成后无需网络 |

### 在线使用

1. 打开 **[查询网页](https://fdhzy.github.io/PEtest/)**。
2. 输入题干里比较有辨识度的几个词，看看匹配结果。
3. 点击题干或「查看详情」，就能看到完整题目、已有选项和来源。

如果结果太多，可以多加一个关键词，用空格隔开；如果没搜到，试着缩短题干，换一两个关键词。

手机上如果在应用里打不开，把网址复制到系统浏览器试试。

### 离线使用

想提前留个备用，可以把整个题库存成一个文件：

1. 打开仓库里的 **[index.html](./index.html)**，点击文件右上方的 **Download raw file（下载原始文件）**。
2. 保存为 `index.html`，注意别变成 `.txt`。
3. 在电脑上双击打开。如果没有自动用浏览器打开，就右键选择「打开方式」，选 Edge、Chrome 或其他浏览器。

也可以 **[下载完整 ZIP](https://github.com/FDhzy/PEtest/archive/refs/heads/main.zip)**，解压后打开里面的 `index.html`。

题库已经装在这个 HTML 文件里了，不用再安装软件，也不用额外下载数据。在线版和离线版的功能、题库相同；离线文件不会自动更新，想用新版时重新下载一份就好。

## 查题时能用到的小功能

- **多个关键词一起搜**：用空格分隔，查找同时包含这些词的题目。
- **查看完整题目**：点击题干或「查看详情」，查看已有选项和出处。
- **按需要筛选**：支持题型筛选，也可以只看有原始选项的题目。
- **显示或隐藏答案**，以及收藏题目、加载更多结果。

收藏存在当前浏览器里。换设备、换浏览器，或从在线版切到离线版时，收藏不会自动跟过去。

## 关于题库，有几件事想说清楚

目前收录了 **6501 道公开旧题库题目**：5730 道判断题、771 道单选题。其中，198 道单选题已恢复原始选项，其余 573 道会明确标注选项缺失。

有些题目能看到答案，却看不到完整选项，是因为现有资料里没有找到。缺的部分先如实留空，等有可靠资料再补上。

**这份题库还没有和今年学习通里的题目逐一核对，旧答案也没有逐题校订。** 查到相似题目时，记得再看一眼题干和选项，尤其不要直接照搬答案字母——选项顺序可能已经变了。

数据快照：2026-11-19。本项目提供开卷考试时手动检索、查看和核对题目的功能，不包含学习通自动答题脚本。
