# PEtest｜体育开卷考试快捷查询

PEtest 是一个用于体育理论开卷考试的题库查询网页，支持通过题干或关键词检索，查看完整题目、已有选项和旧题库答案。提供在线和离线两种使用方式，手机、电脑均可通过浏览器访问，无需安装。

项目基于 **[KevinWang15/fdty](https://github.com/KevinWang15/fdty)** 公开整理的题库制作，希望让同学们在需要时更方便地查找和核对题目。感谢原作者及各位贡献者的整理与分享。

## 使用方式

| 使用方式 | 打开方式 | 网络要求 |
| --- | --- | --- |
| **在线使用** | 通过浏览器打开在线入口，适用于手机和电脑 | 打开或刷新网页时需要网络 |
| **离线使用** | 下载 `index.html` 后用浏览器打开，推荐在电脑上使用 | 下载完成后无需网络 |

### 在线使用

1. 打开 **[查询网页](https://fdhzy.github.io/PEtest/)**。
2. 在搜索框输入题干或关键词，查看匹配结果。
3. 点击题干或「查看详情」，查看完整题目、已有选项和来源。

多个关键词可以用空格分隔。结果较多时，可以增加关键词缩小范围；没有匹配结果时，可以缩短题干或更换关键词。

建议将网址加入浏览器收藏夹，方便后续访问。手机应用内无法打开时，可以复制网址到系统浏览器。

### 离线使用

1. 打开仓库中的 **[index.html](./index.html)**，点击文件右上方的 **Download raw file（下载原始文件）**。
2. 将文件保存为 `index.html`，不要保存为 `.txt`。
3. 在电脑上双击文件，或右键选择「打开方式」，使用 Edge、Chrome 等浏览器打开。

也可以 **[下载完整 ZIP](https://github.com/FDhzy/PEtest/archive/refs/heads/main.zip)**，解压后打开其中的 `index.html`。

题库已包含在这个 HTML 文件中，无需额外下载数据或配置运行环境。在线版与离线版的功能、题库一致；离线版不会自动更新，需要新版时重新下载即可。

## 主要功能

- **关键词检索**：支持完整题干或多个关键词查询，多个关键词用空格分隔并同时匹配。
- **完整题目查看**：点击题干或「查看详情」，查看题目、已有选项及出处。
- **题目筛选**：支持按题型筛选，或仅查看有原始选项的题目。
- **答案与收藏**：支持显示或隐藏答案、收藏题目及加载更多结果。

收藏保存在当前浏览器中，不跨设备或浏览器同步；在线版与离线版的收藏也不会自动同步。

## 题库说明

目前收录 **6501 道公开旧题库题目**，包括 5730 道判断题和 771 道单选题。其中，198 道单选题已恢复原始选项，其余 573 道明确标注选项缺失。现有资料中未找到的选项保留为空，不作推测补全。

**题库尚未与今年学习通版本逐题核对，旧题库答案也未逐题校订。** 使用时请核对题干与选项内容。由于选项顺序可能不同，请勿直接套用旧答案字母。

数据快照：2026-11-19。本项目用于开卷考试时手动检索和核对题目，不包含学习通自动答题脚本。
